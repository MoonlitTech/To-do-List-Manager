# Project Planning

### Project Overview
**Project Name:** To-Do List Manager \
**Description:** Create a Python command-line application that allows users to organize and manage their daily tasks by adding, viewing, completing, and deleting tasks.

### Project Goal
- Practice building a complete Python application from start to finish.
- Improve problem-solving and programming skills.
- Learn how to plan, document, and manage a software project using GitHub.

### Target User
- Myself, as a learning and practice project.

### Problem Statement
- This project provides an easy-to-use solution for managing daily responsibilities.

### Project Requirements
- Allow users to add new tasks.
- Display all existing tasks.
- Mark tasks as completed.
- Delete tasks.
- Save tasks so they remain after the program closes.
- Load saved tasks when the program starts.

### Features
- Add a task.
- View all tasks.
- Mark a task as complete.
- Delete a task.
- Save tasks to a file.
- Load tasks from a file.

### Program Flow
- Launch the program.
- Display the main menu.
- Allow the user to choose an option.
- Perform the selected action.
- Return to the main menu.
- Repeat until the user exits the program.

### Data Planning
- Store the task name.
- Store the completion status of each task.
- Save task information in a file.
- Load the saved information each time the program starts.

### Project Scope
- Develop a basic, fully functional To-Do List Manager.
- Focus on core task management features only.
- Leave advanced features such as due dates, priorities, and categories for future versions.
